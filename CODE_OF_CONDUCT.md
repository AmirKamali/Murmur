# Code of conduct

Be direct, and be decent. Critique the work. Harassment, slurs, and personal attacks are not welcome in issues, pull requests, or discussions on [AmirKamali/Murmur](https://github.com/AmirKamali/Murmur).

Maintainers may edit or hide comments and block accounts that break this. To report a problem, contact the maintainers through a GitHub issue, or a private security advisory if the report itself should stay private.
