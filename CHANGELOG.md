# Changelog

## 1.0.0

First public release as **Murmur**.

- Chromium extension to read a selection, a paragraph, or a page with a local Kokoro voice.
- Popup voice list, live speed and volume, and on-page controls.
- Launchers for macOS (`start-murmur.sh`) and Windows (`start-murmur.ps1`).
- Linux support: TBD.
- Fetches a pinned Kokoro-FastAPI checkout and Kokoro-82M weights on first run.
