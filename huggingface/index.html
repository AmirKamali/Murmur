Murmur

Highlight text on any page and hear it from a Kokoro-82M voice running on this computer.

Source on GitHub Kokoro-82M weights

Run it locally

  1. Install Git and uv. macOS and Windows are supported; Linux is TBD.
  2. git clone https://github.com/AmirKamali/Murmur.git
cd Murmur
./server/start-murmur.sh          # macOS
# .\server\start-murmur.ps1       # Windows PowerShell
  3. Open chrome://extensions, turn on Developer mode, and load the extension/ folder.
  4. Select text and press Alt+R. The popup lists voices and speed.

What stays here

The extension sends the passage to Kokoro-FastAPI on this machine (127.0.0.1:8880). The server returns a WAV from Kokoro-82M. The extension plays that audio.

macOS uses the Apple GPU. Windows defaults to CPU unless you ask for NVIDIA:

$env:DEVICE_TYPE = "cuda"      # NVIDIA
$env:DEVICE_TYPE = "cuda128"   # RTX 50-series
.\server\start-murmur.ps1
Extension: MIT. Model and Kokoro-FastAPI: Apache-2.0. Voices include English, Spanish, French, Hindi, Italian, Japanese, Portuguese, and Chinese.
